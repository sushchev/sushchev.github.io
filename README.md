# Iscrop website

Static website for https://iscrop.ru/, published with GitHub Pages from `main`.

The visual identity uses the approved flat 67-ray mark, with a planet diameter equal to 50% of the sun's outer diameter. Core colours: navy #18243A, amber #FCA41D, plum #7F0043.

The laboratory, optical module and signal board photographs are AI-generated conceptual visualisations, not documentary photographs or a catalogue of actual Iscrop products. They are labelled as concepts in the interface and image descriptions. The SVG celestial artwork is built from the approved vector mark.

No build step is required. Serve this folder with a static HTTP server. The site supports reduced motion, keyboard-operated tabs and image viewer, an image carousel, and a simplified interference experiment.
