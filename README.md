# Iscrop website

Static website at https://iscrop.ru/, published by GitHub Pages from `main`.

## Visual system

The visual language is built around continuous fields, signal paths and discrete structures. The symbol is a signature in the header and footer. The flat approved 67-ray mark and the planet/sun diameter ratio of 50% are unchanged.

Core colours: navy #18243A, amber #FCA41D, plum #7F0043. Manrope is self-hosted. The three SVG study families have separate, less dense mobile variants. The hero studies support pointer and keyboard selection.

The laboratory and device photos are AI-generated conceptual visualisations, labelled in the interface. They are not documentary photos or an actual product catalogue.

## Running

No build step is required. Serve the folder with a static HTTP server. Features include accessible tabs, an image gallery and viewer, reduced motion controls, and a simplified interference experiment.
